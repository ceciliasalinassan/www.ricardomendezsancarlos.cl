# Club Deportivo Ricardo Méndez - Versión Pro Admin

Incluye:
- Diseño ordenado negro/dorado estilo deportivo premium.
- Letras más pequeñas y mejor jerarquía visual.
- Página pública para todos.
- Panel administrador privado.
- Clave demo: admin1932
- Carga de noticias, fotos/videos y fixture.
- Solicitudes de socios pendientes de aprobación.
- Guardado local con localStorage.

IMPORTANTE:
Este guardado local no se pierde al actualizar el navegador, pero solo queda en el mismo equipo/navegador.
Para que funcione online desde todos los celulares/computadores y no se pierda nunca, se debe conectar a Supabase con:
- Login administrador real.
- Base de datos para noticias, galería, fixture, socios y solicitudes.
- Storage para fotos y videos.
- Políticas RLS para que solo el administrador apruebe/publice.
