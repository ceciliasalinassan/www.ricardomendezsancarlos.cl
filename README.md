Mejoras:
- Usa toda la pantalla y evita que se vea cortada.
- Menú lateral con botones e íconos.
- Letras un poco más grandes.
- Estilo deportivo premium negro, dorado y azul eléctrico.
- Fondo más potente con estadio, luces y efectos.
- Logo sin fondo blanco.
- Tabla de posiciones por serie seleccionable.
- Panel administrador para cargar puntajes por serie.
- Sección Historia del club y presidente actual editable.
- Sección auspiciadores editable.
- Solicitudes de socios con aprobación.
- Clave demo admin: admin1932

Importante:
El guardado actual usa localStorage. Para que la información no se pierda entre celulares/computadores hay que conectar Supabase.
